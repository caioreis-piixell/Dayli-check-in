# Presença Local

Página de vendas do ebook Presença Local, por Caio.

## Oferta configurada

- De R$199,90 por R$19,90.
- 90% de desconto (arredondado).
- Checkout: https://pay.kiwify.com.br/h3BFiYP
- Cinco botões de compra apontam diretamente ao checkout.

## Arquivos

`index.html` contém toda a página, estilos, interações e capa original incorporada em WebP. Não precisa instalar dependências ou executar build. O PDF integral do produto não faz parte do site público.

## Teste local

Baixe `index.html` e abra no navegador. Confira o layout no computador e celular, as abas de exemplos, as perguntas frequentes e os botões de compra. Confirme o produto e o preço no checkout antes da divulgação.

## Publicação na Hostinger

Envie `index.html` para a pasta pública do site ou para a subpasta desejada usando o gerenciador de arquivos. Se já existir um site nessa pasta, faça backup e escolha o destino correto antes de substituir seu arquivo inicial.

## GitHub Pages

Em Settings → Pages, escolha publicação por branch, branch `main` e pasta raiz `/`. Salve e aguarde o GitHub fornecer a URL. A hospedagem não é ativada apenas pelo envio dos arquivos.

## Enter

Importe/conecte este repositório na plataforma e selecione publicação estática, se disponível. A conexão e a publicação no Enter não foram executadas nesta entrega.

## Edição da oferta

A configuração `OFFER` fica no final do HTML. Ao trocar o checkout, atualize também os cinco links de compra no HTML, para manter o funcionamento sem JavaScript. Ao alterar preços, atualize o preço de referência, o desconto, os CTAs e a configuração.

## Verificação realizada

HTML balanceado, IDs únicos, âncoras internas, sintaxe JavaScript e cinco links de compra conferidos. Não houve compra real, teste visual em navegador ou publicação automática. O conteúdo não contém depoimentos inventados, garantia de resultados ou contagem regressiva artificial.
